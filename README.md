# ⚡ جرقه: ماجرای پیام عصبی

بازی سه‌بعدی ماجراجویی (لمسی، مناسب اندروید) برای **علوم هشتم، فصل ۴: تنظیم عصبی**.

- مرحله‌ی ۱ — درون نورون: دندریت، جسم سلولی، آکسون، غلاف میلین، سیناپس
- مرحله‌ی ۲ — جاده‌ی عصب: عصب حسی و حرکتی، انعکاس، نخاع
- مرحله‌ی ۳ — شهر مغز: مخ، مخچه، بصل‌النخاع
- مرحله‌ی ۴ — نبرد با غول گیجی (مرور در قالب مبارزه)

اجرای محلی: `node serve.js` و سپس `http://localhost:8765`
